# Hackatón de Accesibilidad 2026

Repositorio de documentación y materiales de la Hackatón de Accesibilidad 2026.

Este repositorio contiene presentaciones, desafíos, documentación y material generado durante la organización y desarrollo de la hackatón.

## Acerca de la Hackatón

La Hackatón de Accesibilidad 2026 fue un encuentro interdisciplinario orientado al diseño y desarrollo de soluciones tecnológicas que contribuyan a reducir barreras de accesibilidad y promover una participación más inclusiva en distintos ámbitos.

La actividad reunió estudiantes, docentes, organizaciones y profesionales de diversas áreas con el objetivo de colaborar en la construcción de prototipos y propuestas centradas en las necesidades de las usuarias.

## Vinculación con cátedras

En la edición 2026 se propuso a distintas cátedras la posibilidad de vincular trabajos finales de cursada con proyectos desarrollados durante la hackatón.

El objetivo de esta iniciativa fue promover una mayor participación estudiantil, incentivar la continuidad de los proyectos más allá del evento y generar experiencias de aprendizaje aplicadas sobre problemáticas reales de accesibilidad.

El seguimiento de estas articulaciones quedó a cargo de las cátedras participantes y de la Dirección de Accesibilidad.

## Desafíos propuestos

1. Asistente cognitivo para formularios complejos

Diseñar un sistema que acompañe a las personas durante la realización de trámites e inscripciones mediante lenguaje claro, explicaciones contextuales y asistencia paso a paso.

2. Mapa accesible de la Facultad

Desarrollar una herramienta que permita identificar rutas accesibles, barreras arquitectónicas y puntos de interés relevantes para personas con distintas necesidades de accesibilidad.

3. Auditor inteligente de accesibilidad con IA

Construir una herramienta capaz de analizar sitios web, detectar problemas de accesibilidad y ofrecer explicaciones y recomendaciones comprensibles para su resolución.

4. Intérprete básico de lengua de señas con visión por computadora

Desarrollar un prototipo capaz de reconocer gestos básicos mediante una cámara y facilitar la comunicación en contextos donde no hay intérpretes disponibles.

## Infraestructura de trabajo

Para facilitar la colaboración durante la hackatón se preparó una infraestructura compuesta por repositorios, equipos y tableros de seguimiento.

### Organización de equipos

Se preparó una estructura inicial de 10 equipos de trabajo, dado que se inscribieron 63 participantes.

```text
team-01 → hackaton-2026-proyecto-01 → flujo-trabajo-proyecto-01
team-02 → hackaton-2026-proyecto-02 → flujo-trabajo-proyecto-02
...
team-10 → hackaton-2026-proyecto-10 → flujo-trabajo-proyecto-10
```

### Gestión de proyectos

Cada repositorio incluía:

- README inicial
- Plantillas de Issues
- Tablero Kanban mediante GitHub Projects

Estas herramientas buscan favorecer la organización de tareas, registrar avances y coordinar el trabajo colaborativo.

## Observaciones técnicas

Durante el desarrollo de la hackatón se registraron algunos inconvenientes relacionados con la autenticación en GitHub desde los entornos locales de trabajo.

El problema más frecuente fue la aparición de errores HTTP 403 al intentar realizar operaciones de push mediante Git.

En la mayoría de los casos la situación se resolvió mediante:

- Reautenticación utilizando GitHub CLI (GH).
- Configuración de autenticación mediante claves SSH.

La experiencia mostró la conveniencia de contar con una guía rápida de autenticación y configuración de GitHub para futuras ediciones.
